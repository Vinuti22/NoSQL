# Требования и Access Patterns (вариант 15)

## Функциональные (6+)
| № | Требование |
|---|---|
| FR1 | Регистрировать движение товара (IN/OUT/TRANSFER/ADJUST) с количеством, оператором и документом-основанием |
| FR2 | Просматривать все операции склада за выбранную дату (новые сверху) |
| FR3 | Просматривать последние N операций склада за дату и операции за интервал времени |
| FR4 | Просматривать историю движений товара за месяц и за интервал |
| FR5 | Исправлять комментарий операции и удалять ошибочные операции (в обеих таблицах) |
| FR6 | Получать итоги по типам операций за день и оборот товара по месяцам |

## Нефункциональные (3+)
| № | Требование |
|---|---|
| NFR1 | Чтение по ключу партиции — единицы миллисекунд; никаких `ALLOW FILTERING` |
| NFR2 | Размер партиции ограничен бакетом (склад+день, товар+месяц) |
| NFR3 | Воспроизводимость: запуск одной командой `docker compose up`, данные заполняются скриптом |

## Access Patterns (8)
| AP | Запрос | Таблица | Приоритет | Ожидаемый результат |
|---|---|---|---|---|
| AP1 | Все операции склада за день | by_warehouse_day | Высокий | список по ts DESC |
| AP2 | Последние N операций склада за день | by_warehouse_day | Высокий | N строк (LIMIT) |
| AP3 | Операции склада за интервал времени | by_warehouse_day | Средний | срез по clustering key ts |
| AP4 | Итоги по типам за день | by_warehouse_day | Средний | словарь тип → сумма |
| AP5 | История товара за месяц | by_product | Высокий | список по ts DESC |
| AP6 | Последние N движений товара | by_product | Высокий | N строк (LIMIT) |
| AP7 | Движения товара за интервал | by_product | Средний | срез по ts |
| AP8 | Оборот товара по месяцам | by_product | Низкий | чтение нескольких бакетов, свёртка |

Нетривиальные запросы: Q4 (агрегация в приложении) и Q8 (fan-out по партициям-бакетам).
